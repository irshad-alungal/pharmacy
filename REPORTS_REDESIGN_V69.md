# Reports & Analytics redesign (version 69)

`reports.html` now follows the attached design, desktop and mobile. The sidebar, top bar, bell and mobile bottom navigation match the dashboard, and there is no "Your Trusted Healthcare Partner" block. Access is still Admin and Super Admin only (`reports.view`).

## Run once in Supabase
**`database/migrations/0029_reports_analytics.sql`**, then check it with `database/diagnostics/verify_0029.sql` (every row true). Safe to run twice. Nothing existing is changed:
- **`reports_overview(from, to)`** — sales, orders, registered / walk-in customers, purchases, expenses, estimated net profit and margin (same maths as the Profit & loss report: FIFO cost of medicines sold), sales and purchase returns — for the chosen range **and the previous range of the same length**; plus low-stock, out-of-stock, near-expiry and stock value now.
- **`reports_sales_by_category(from, to)`** — each bill total is shared across its lines, so the categories add up exactly to total sales. Medicines with no category show as *Uncategorised*.
- **`report_runs`** + `report_run_log / report_runs_list / report_run_delete` — the **Recent Reports** history: who generated which report, for which period, when. Shared by all admins of the branch (newest 500 kept).

Before 0029 is run the page still works: the KPIs come from the existing reports, history is kept in the browser, and a note asks you to run 0029.

## The page
- **Header:** date range picker (Today, Yesterday, Last 7 Days, This Week, This Month, Last Month, Last 30 Days, This Quarter, This Financial Year, This Year, or any From–To), **Generate Report**, **Export** (overview PDF / Excel, daily sales-purchases-expenses Excel, sales by category Excel, print overview).
- **Report types:** Sales, Purchase, Inventory, Customer, Distributor, Expense, Finance, Returns, Custom. Clicking one opens the report generator with its reports. On mobile: the first 4 + **More**.
- **Report Overview:** Total Sales, Total Purchases, Total Expenses, Net Profit, Profit Margin — each vs the previous period. Click a KPI to open its report.
- **Sales Trend:** the selected period (daily; weekly / monthly for long ranges), Last 7 / 30 Days, Last 12 Months; tooltip with bills and returns.
- **Sales by Category:** donut, top 5 + Others, share and amount.
- **Key Insights:** sales change vs previous period · orders from customers (registered + walk-in, average bill) · low stock / out of stock / expiring batches / stock value · returns count and value (and purchase returns).
- **Recent Reports:** name, type, period, generated on, generated by; ⬇ PDF / Excel / CSV / Print and 👁 view (recalculated from current data); type filter; **View All Reports** with *Run again for the selected period* and *Remove from history*.
- **Quick Reports:** Today's Sales, This Month's Summary, Stock Valuation, Top Customers, Top Selling Medicines.
